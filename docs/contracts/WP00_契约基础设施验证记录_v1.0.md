## 5. 已验证内容

### 5.1 OpenAPI 结构

- 三份 OpenAPI YAML 均可被 SnakeYAML 解析；
- `openapi` 版本为 3.0.3；
- 会员中心 1 个、POS 4 个、青禾平台 35 个 operation；
- operationId 在单文件和跨文件范围内不重复；
- 每个 operation 存在 responses；
- 当前所有本地 `$ref` 均能解析到目标节点；
- 青禾平台契约包含会员领取、卡包、活动审批、库存调整、链路查询、对账、结算确认和导出路径。

### 5.2 会员中心 Mock

已自动验证：

- ACTIVE Token 返回最小会员身份；
- 无效 Token 返回 TOKEN_INVALID；
- 冻结会员返回 MEMBER_FROZEN；
- 限流返回 RATE_LIMITED 和 Retry-After；
- 超时场景稳定延迟并返回 SYSTEM_BUSY，不默认放行；
- 缺少契约请求头被拒绝。

Mock 另外支持过期、注销和故意缺字段响应，用于后续适配器失败测试。

### 5.3 POS 模拟客户端

已自动验证：

- HMAC-SHA256 规范串顺序与接口说明一致；
- 签名输出为 64 位十六进制小写；
- 相同输入产生相同签名，业务字段变化导致签名变化；
- 写请求头与 body.posRequestNo 一致；
- 查询原结果沿用原 posRequestNo 且不伪造写请求头；
- 无稳定 posRequestNo 时不能构造核销请求；
- 密钥不进入规范串或业务请求体。

### 5.4 对账文件 fixtures

已自动验证：

- 正常文件表头、行数、日期、枚举和 checksum 一致；
- 只有表头的文件是合法零交易日；
- 相同 provider + batchNo、不同 checksum 可被识别为冲突；
- 坏业务日期/操作类型/发生时间的行被拒绝，不能静默忽略；
- manifest JSON Schema 包含 batchNo、rowCount、checksum 和更正批次字段。

## 7. 使用方式

### 7.1 自动验证

执行第 3 节 Maven 命令。测试会自动启动和关闭随机端口的会员中心 Mock，不占用固定端口。

### 7.2 手工启动会员中心 Mock

在 IDE 中运行：

```text
com.qinghe.marketing.contract.mock.MemberCenterMockServer.main
```

默认监听 `127.0.0.1:18081`，可传第一个程序参数覆盖端口。该 main 位于 test source，仅用于本地契约联调，不进入生产制品。

支持 Token：

```text
mock-member-token-active
mock-member-token-invalid
mock-member-token-expired
mock-member-token-frozen
mock-member-token-cancelled
mock-member-token-rate-limited
mock-member-token-timeout
mock-member-token-malformed
```

### 7.3 POS 模拟客户端

`PosContractClient` 位于 test source，可构造 verify、redeem、queryRedemption 和 reverse 请求。只有真实青禾 POS API 在 WP-06 出现后，才能执行端到端业务断言。
