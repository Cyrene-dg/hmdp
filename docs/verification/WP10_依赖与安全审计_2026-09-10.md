# WP-10 依赖与安全审计

> 审计日期：2026-09-10  
> 结论：已修复 3 个直接依赖 Critical 命中；旧 Spring Boot 2.3 依赖树仍存在大量公开漏洞命中，因此仅允许作为本地模拟与求职演示基线。任何真实部署必须先完成受支持框架基线迁移并重新审计。

## 1. 方法与工具

### 1.1 依赖树

```powershell
mvn dependency:tree -Dscope=runtime
```

原始运行时基线包括 Spring Boot 2.3.12.RELEASE、Spring Framework 5.2.15.RELEASE、Tomcat 9.0.46、Jackson 2.11.4、Logback 1.2.3、RabbitMQ Client 5.9.0、Netty 4.1.65.Final、Hutool 5.7.17、MyBatis-Plus 3.4.3 和 Redisson 3.16.8。

### 1.2 扫描器

OWASP Dependency-Check 13.0.0 做了两次尝试：第一次因 Java truststore 无法验证 RetireJS 数据源证书而失败；禁用 RetireJS 后，第二次因 NVD 数据库无 API key 且本地缓存为空而失败。这两次只能记录为“扫描器未取得结果”，绝不能记成零漏洞。

随后使用官方 OSV-Scanner Docker 镜像 v2.5.0：

```powershell
docker run --rm -v "${PWD}:/src" ghcr.io/google/osv-scanner:v2.5.0 `
  scan source --format=json `
  --output-file=/src/target/wp10-osv-report.json `
  --experimental-exclude=target --experimental-exclude=.git `
  --recursive /src
```

JSON 原始报告保存在忽略目录 `target/`，不提交 Git；本文件保存可复查命令、汇总和处置决定。

## 4. 为什么不在 WP-10 零散覆盖 Spring/Tomcat/Netty 版本

剩余命中高度集中在 Spring Boot 2.3 管理的成组依赖和旧 Redisson/Redis 组合。单独覆盖 Tomcat、Jackson、Spring Framework、Spring Data、Netty、Rabbit Client 和 Logback 会破坏 BOM 的兼容性假设；即使某个 jar 的版本号变新，也不能证明整个组合受支持。

同时，升级到当前 Spring Boot 主线会涉及：

- Java 与 Spring Boot 基线变化；
- `javax.servlet` / `javax.annotation` 到 Jakarta 命名空间迁移；
- Spring Data Redis 与 Lettuce 版本重新对齐；
- Redisson starter 兼容矩阵变化；
- MyBatis、测试框架、配置属性和序列化行为回归；
- 旧点评入口与青禾隔离上下文的全量回归。

这不是 WP-10 中可以诚实称为“小修”的动作，应作为独立框架迁移工作包执行。

## 5. 风险决议

| 使用场景 | 决议 |
|---|---|
| 本地模拟、课程学习、面试讲解 | 允许继续，但 README 和简历不得声称生产上线或生产安全达标 |
| 公网演示 | 暂不允许；至少先升级受支持框架基线、关闭旧入口、配置外部密钥并复扫 |
| 真实试点/生产 | BLOCKED；必须先完成框架与中间件客户端迁移、SCA 复扫、全量 Gate、渗透/配置审查及真实发布审批 |

WP-10 的“模拟试点条件”只评价业务状态机、幂等、恢复与本地基础设施验证。它不覆盖真实生产安全门槛。

## 6. 后续迁移建议

1. 从独立分支建立受支持的 Spring Boot 基线，不在 `main` 或当前稳定集成分支上直接试升；
2. 先让纯青禾上下文编译和测试通过，再迁移旧点评入口；
3. 清除手工钉住的 Spring Data Redis/Lettuce 版本，恢复同一 BOM 管理；
4. 选择与目标 Spring Boot 明确兼容的 Redisson/MyBatis starter；
5. 完成 Jakarta import、配置属性、序列化和 MockMvc 迁移；
6. 使用可用的 NVD API key 重跑 Dependency-Check，同时重跑 OSV；
7. 对 Critical/High 逐条记录可达性、配置条件、修复版本和责任人；
8. 重跑全部单元、MySQL、Redis、RabbitMQ、迁移回滚和系统旅程 Gate。
