## 3. 依赖审计决议

OSV 首次按 package + advisory 去重为 157 个命中；直接升级后为 154 个，Critical 从 20 降到 17。剩余命中主要集中在 Spring Boot 2.3.12、Tomcat 9.0.46、Spring Framework 5.2.15、Jackson 2.11.4、Logback 1.2.3、Netty 4.1.65 和 Rabbit Client 5.9.0。

这些数字是版本匹配，不等于 154 条已证明可利用漏洞；但也不能视为零风险。零散覆盖 BOM 版本会制造未经支持的组合，因此决议为：

- 本地模拟/面试演示：允许，必须保留非生产声明；
- 公网演示：暂不允许；
- 真实试点/生产：BLOCKED，先完成独立 Spring Boot/中间件客户端迁移、重新 SCA 和完整 Gate。

详见 `docs/verification/WP10_依赖与安全审计_2026-09-10.md`。
