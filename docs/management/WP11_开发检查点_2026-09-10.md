## 2. 旧入口隔离 Gate

新增 `LegacyEndpointIsolationTest` 并扩展 `QingheIsolatedContextTest`，覆盖：

1. 未配置开关时九个旧 Controller 均不注册；
2. 显式设置 `legacy.hmdp.endpoints-enabled=true` 时兼容入口可注册；
3. 九个 Controller 使用同一 opt-in 条件；
4. 默认 Spring Boot 配置源位于青禾包；


## 5. 环境插曲与结论边界

- 第一次自动就绪脚本在测试执行前报告临时基础设施未就绪，并在 `finally` 中删除容器；因容器已按设计清理，未将无法复核的具体原因写成结论。随后分开启动三项并检查日志，均正常 ready；
- 第二次命令把含 `&` 的 JDBC URL 经 Windows `mvn.cmd` 传递，批处理将其拆成额外命令；该轮只执行了 Maven clean，JUnit 未开始。改为无 `&` 的等价临时 URL 后完整 Gate 通过；
- 首次路由冒烟测试只 Mock 了 `StringRedisTemplate`，Redisson 自动配置仍尝试连接本机 Redis，导致上下文失败；测试明确排除 Redisson 自动配置后，只隔离路由测试不关心的外部连接，真实 Redis 行为仍由完整 Gate 覆盖；
- 这两次均属于测试环境/命令编排失败，不计入代码通过结果，也没有被删除或伪装成测试成功。
